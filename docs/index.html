bandit-exp

いろんなバンディットアルゴリズムを、複数の問題設定で公平に比較するためのベンチマーク
すべての問題設定は ベルヌーイ・バンディット（各腕を引くと 0/1 の報酬が返る）。 違いは「各腕のクリック確率が時間とともにどう決まるか」だけ。 各環境には乱数生成器を注入しており、シードを固定すれば全アルゴリズムを 同一の報酬系列で評価できる（＝公平な比較）。 リグレット = Σ_t (最適腕の期待報酬 − 選んだ腕の期待報酬)。
各アルゴリズムは「どの腕を選んだか」と「得た 0/1 報酬」しか見ない （環境の真の確率は決して覗かない）。これも公平性の担保。 表記: n_i = 腕 i の表示回数、 c_i = クリック回数、 CTR_i = c_i / n_i、 N = Σ n_i（総表示回数）。
